# K-Formula Check

Validation MVP for comparing Korean and U.S./regional versions of K-beauty products.

## Included in v0.1
- premium editorial-style K-beauty landing page
- product search
- verdict system: Same Formula / Different Formula / Market-Specific Product / Not Confirmed
- five sourced test product pages
- robots.txt + sitemap.xml
- Vercel static deployment config

This project is intentionally small for organic-search validation before expanding the database.
